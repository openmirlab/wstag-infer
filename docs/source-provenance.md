# Source and checkpoint provenance

The original research is [Towards Weakly Supervised Text-to-Audio Grounding](https://arxiv.org/abs/2401.02584) by Xuenan Xu, Ziyang Ma, Mengyue Wu, and Kai Yu. The [research repository](https://github.com/wsntxxn/TextToAudioGrounding) at commit `40c2280139a9bd077a6c823319d6244f5aa7512d` contains an MIT LICENSE; see `LICENSE.UPSTREAM-MIT`. It also contains training, dataset, and evaluation code, none of which is included in this package's installed surface.

The model implementation copied into `_impl/modeling_wstag.py` comes from the author's [Hugging Face snapshot](https://huggingface.co/wsntxxn/cnn8rnn-w2vmean-audiocaps-grounding/tree/a9eb20c3e2135e0ca82d747bb99ae10ee4eaec66) at revision `a9eb20c3e2135e0ca82d747bb99ae10ee4eaec66`, file `hf_modeling_grounding.py`, SHA-256 `8b88809c2f640ab0d7291b1190786fb81e88b3ddefa38c1a94b004c2d5c1048b`. The only local change to that file is its opening navigation/provenance docstring. The HF model card labels the snapshot Apache-2.0; its file tree does not contain a separate LICENSE file. The GitHub and HF files differ, so both sources and their license statements are recorded separately.

The package downloads only `config.json`, `model.safetensors`, and `vocab.json` from that fixed revision, validates the SHA-256 values in `src/wstag_infer/config/checkpoints.toml`, and loads the adapted local model class. Runtime loading never executes remote Python code or uses the HF snapshot's unfixed remote `from_pretrained(repo_id)` vocabulary lookup. A caller can provide a verified local checkpoint directory for offline use. Checkpoint bytes remain outside Git and outside the package wheel.

The original direct `AutoModel` CPU output was recorded before package work in `tests/fixtures/upstream_cpu.json` using the generated `synthetic_events.wav`; it contains nontrivial glass and siren score curves and genuine trailing silence. The source environment was Python 3.12, Torch 2.15.0, TorchAudio 2.11.1, Transformers 4.57.6, CPU with four intra-op threads. `pytest -m model` compares the installed package's in-memory floats against that author baseline. The fixture was generated before copying and modifying the model file. Numeric parity is separate from model localization accuracy.
